## Standardized Classification Key

Every feature in SG CUBE is categorized strictly under one of the 8 authoritative engineering statuses:

1. **`FULLY IMPLEMENTED + REAL-RUNTIME VERIFIED`**: Code is complete, integrated end-to-end, tested against real hardware/operating system in the installed application, and verified functional.
2. **`IMPLEMENTED + AUTOMATED TEST VERIFIED`**: Code is fully implemented and passes comprehensive automated unit/integration test suites, but depends on specific mocked or simulated hardware in headless test runs.
3. **`IMPLEMENTED BUT PARTIALLY WORKING`**: Feature works for standard scenarios but degrades, fails, or exhibits incomplete edge-case handling.
4. **`IMPLEMENTED BUT UNSTABLE`**: Feature exists and executes, but displays timing issues, crashes, race conditions, or unhandled exceptions under stress.
5. **`IMPLEMENTED IN CODE BUT NOT INTEGRATED`**: Feature module or class is fully written, but is not wired into `command_router.py`, `vision_engine.py`, or GUI presentation layers.
6. **`PLANNED / SPECIFICATION ONLY`**: Referenced in architecture documentation or roadmap comments, but no functional code exists.
7. **`NOT IMPLEMENTED`**: Desired capability is completely absent from the codebase.
8. **`BLOCKED BY HARDWARE / ENVIRONMENT`**: Code is complete and correct, but cannot function due to missing physical hardware, external API unavailability, or OS permission barriers.
